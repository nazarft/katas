# Katas

Ejercicios de programación.

## Morse

`morse/` contiene una solución en Java que encuentra las frases posibles para un mensaje Morse sin separadores usando las palabras de `src/main/resources/words.txt`.

Para ejecutar desde `morse/` con Java 21 y Maven:

```text
mvn package
java -cp target/classes io.nazar.Main
```

La secuencia del ejercicio devuelve cinco combinaciones, incluida `may the force be with you`.
